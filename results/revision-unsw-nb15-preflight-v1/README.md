# UNSW-NB15: acquisition, preflight and 25-feature windows

Third external dataset, chosen because attacks and normal traffic share the same capture
periods (the condition missing from Data22 and ToN-IoT, where attacks occur on separate
dates). Publisher: UNSW Canberra Cyber Range (IXIA PerfectStorm); free academic use with
citation of the five papers listed on the official page
(https://research.unsw.edu.au/projects/unsw-nb15-dataset).

## Acquisition

The four official CSVs (`UNSW-NB15_1.csv` … `_4.csv`) were downloaded manually from the
publisher's SharePoint folder as `OneDrive_1_10-11-2026.zip` and copied to
`data/unsw-nb15/` (not tracked). SHA-256 values are in `data/unsw-nb15/SHA256SUMS` and in
`preflight.json`. The CSVs have no header; the 49-column order follows the publisher's
feature list (`UNSW-NB15_features.csv`, not yet downloaded; every row has 49 fields and
time/label fields fall in the expected positions).

## Preflight (`scripts/unsw_nb15_preflight.py`, `preflight.json`)

- 2,540,047 records (publisher states 2,540,044); 0 malformed rows; no negative numeric
  values; 7 missing destination ports.
- Two capture sessions: 2015-01-22 11:49 UTC to just after midnight, and 2015-02-18;
  1,441 occupied minutes.
- 321,283 attack records (12.6%): Generic 215,481, Exploits 44,525, Fuzzers 24,246,
  DoS 16,353, Reconnaissance 13,987, Analysis 2,677, Backdoor 1,795 + Backdoors 534
  (merged), Shellcode 1,511, Worms 174. `Label` and `attack_cat` never conflict.
- **805 of 1,441 minutes contain both benign and attack records; no minute is attack-only.**

## Representation differences (approved mapping)

| Contract feature | UNSW-NB15 source | Note |
| --- | --- | --- |
| responder host / port | `dstip`, `dsport` | port 0 or missing excluded, as in Data24 |
| duration | `dur` | |
| originator / responder bytes | `sbytes`, `dbytes` | UNSW *transaction* bytes; Data24/ToN-IoT use payload bytes |
| packets | `Spkts`, `Dpkts` | |
| protocol | `proto` (135 values) | tcp/udp/icmp, rest → other |
| service | `service` | dns/http/ssl/ssh; `-` (49% of records), ftp, smtp, … → other |
| connection state | `state` (**Argus**, not Zeek) | FIN, CON → SF; INT, REQ → S0; RST → RSTO; others (<0.1%) → other |

The state mapping is a declared modelling choice; attacks are 81% `INT` (→ S0) and benign
records 64% `FIN` (→ SF). A sensitivity variant without the six state features is planned.

## Windows (`scripts/unsw_nb15_windows.py`)

Grouping and formulas follow Data24 (`build_window_row`): UTC day and floor(Stime/60) over
all records. Twelve randomly sampled windows were recomputed with the reference function
(maximum relative difference 5e-13).

- 1,441 windows: 636 benign, 805 attack (any attack record).
- Attack windows are diluted: median attack-record fraction 0.119 (10th percentile 0.047).
- 802 of 805 attack windows contain several attack categories, so family-level analyses
  (e.g. leave-one-family-out) are not possible at window level.
- Window file SHA-256 `a82cef4b…` (`artifacts/unsw-nb15-windows-v1/windows.json`).

Limits: small number of windows (two sessions); synthetic attacks generated by a traffic
tool; same publisher group as ToN-IoT, different testbed; labelling issues reported in the
literature are not re-audited here.
